# 前端选品台 · 原型 v1（隔离目录）

这是第一版**最小闭环原型**，与后续正式版本严格隔离，只占用本目录。

## 定位

给不懂前端的客户用的"前端选品台"：像在 4S 店选配汽车一样，把前端需求拆成可选模块 + 风格，拖进空白画布实时预览效果，最后导出一份给 AI（Codex）的结构化配置单，约束 AI 只做"按单组装"，减少猜测和 token 消耗。

## 本版已实现的最小闭环

- 模块库：8 个通用页面模块（导航、主视觉、特性、画廊、价格、FAQ、行动号召、页脚），每个带"通俗名 + 技术名 + 缩略图标"三件套
- 拖拽落地：从左侧拖模块进画布，"落地生根"并即时渲染
- 主题换肤：4 套皮肤（极简 / 科技蓝 / 暗黑 / 玻璃拟态），一键全局换肤
- 交互变体示例：FAQ 支持"手风琴展开 / 抽屉滑出"两种，回应"知道效果但说不出名字"的痛点
- 导出配置单：`spec.json`（对齐 Automattic site-spec 结构）+ `spec.md`（人机可读）

## 使用方式

零依赖、离线可用。直接用浏览器打开本目录下的 `index.html` 即可，双击运行。

## 与正式版的隔离约定

- 本目录是**一次性原型**，只用于验证手感，不做长期演进
- 正式版将在工作区另起目录开发，schema、架构、代码从这里"借鉴结论"而不是"继承代码"
- 本目录内的临时决定不得自动成为正式版的约束

## 技术说明

- 纯原生 HTML + CSS + JavaScript，内联实现，无任何 CDN / 构建依赖
- 页面渲染模型对齐 Flexilte 的 `LayoutConfig` 递归树思路（模块 + 变体 + 顺序）
- 导出 schema 对齐 Automattic `site-spec` 的"页树 + 事实字段"思路
- 主题层使用 CSS 变量，预埋 W3C Design Tokens 的对接点
